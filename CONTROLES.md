# Comandos — Cube Fight

- **Jogador 1:** WASD para mover, pular (W) e defender (S); F para M1; G para especial.
- **Jogador 2:** setas para mover, pular (↑) e defender (↓); / para M1; . para especial.
- **Controle:** analógico para mover/mirar; analógico para cima para pular; para baixo para escudo/parry; RT/R2 para M1; RB/R1 para especial.
- **Mobile:** joystick, ATACAR e SKILL nas respectivas áreas de cada jogador.
- No modo contra bot, os controles touch ficam agrupados do lado esquerdo.
- No modo Infinito, o mapa muda a cada cinco mortes somadas; pause para encerrar e conferir o placar.
